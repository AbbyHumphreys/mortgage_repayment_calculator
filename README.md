# Mortgage Repayment Calculator

A responsive mortgage calculator built with **React** and **TypeScript**.  
It calculates estimated monthly payments for **repayment** and **interest-only** mortgages, with form validation and a clean, user-focused UI.

This project was originally based on a Frontend Mentor design brief and has been developed with a focus on maintainable component structure, accessibility, and clear business logic.

---

## Features

- Repayment and interest-only mortgage calculations
- User-friendly form with validation and error messages
- Responsive layout for mobile and desktop
- Clear results summary
- Built using modern React patterns

---

## Tech Stack

- React
- TypeScript
- Sass (SCSS)

---

## Getting Started

### Install dependencies
```bash
yarn install
```

### Run locally
```bash
yarn start
```
